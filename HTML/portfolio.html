Projeto AV1

Portfólio Pessoal

Este portfólio foi criado para demonstrar minhas habilidades em HTML e CSS, com foco em uma navegação fácil e design atraente. Utilizei HTML5 para estruturar o conteúdo e CSS3 para estilização, aplicando práticas modernas como Flexbox e Grid Layout. O design é responsivo, funcionando bem tanto em desktops quanto em celulares.

O principal objetivo foi criar uma página pessoal simples e intuitiva. Enfrentei alguns desafios na organização do conteúdo e na responsividade, mas o projeto me ajudou a evoluir bastante em estruturação, usabilidade e design front-end.

Projeto AV2

Site Empresarial

Este projeto apresenta o desenvolvimento de um site empresarial com navegação intuitiva e design profissional. Usei HTML5 para estruturar o conteúdo, CSS3 para estilização, JavaScript para interatividade e PHP para o backend, com funcionalidades como formulários de contato e gerenciamento de conteúdo.

O site é responsivo, com boa visualização em dispositivos móveis e desktops. Foi uma ótima experiência para entender como essas tecnologias trabalham juntas em projetos reais.
