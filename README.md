# 🌐 Página Pessoal - Primeiro Contato com Web Dev

Este foi o meu primeiríssimo projeto acadêmico focado em desenvolvimento Web, realizado durante o 1º período da faculdade de Ciência da Computação pela Veiga de Almeida. O objetivo principal do projeto foi fixar os conceitos iniciais e estruturais das tecnologias base da internet.

### 🛠️ Tecnologias Utilizadas
- **HTML5:** Para a estruturação de tags, textos e seções da página.
- **CSS3:** Para os conceitos iniciais de estilização, cores e fontes.

### 🎯 O que eu pratiquei nesse projeto:
- Estruturação semântica de uma página web.
- Uso de seletores e propriedades básicas de CSS.

*Nota: Este projeto possui fins estritamente didáticos e representa o meu ponto de partida na jornada de desenvolvimento de software!*
